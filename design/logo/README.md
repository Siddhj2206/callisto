# Callisto logo

The mark from the project's logo kit (shared by that family of editions). Only
the mark is used here: the kit's wordmarks spell other names.

- `callisto-logo.svg`: full colour, 64 px and up.
- `callisto-logo-small.svg`: simplified cut for 48 px and below.
- `callisto-logo-mono-white.svg`: one colour, for dark backgrounds.
- `png/`: rendered by the kit. 16 to 48 come from the small cut.
  `callisto-logo-boot.png` is kept for a boot splash.

The SVGs use clip paths, which Qt's SVG renderer does not draw, so everything
that Qt reads (shell, installer, icon theme) uses the PNGs.

Night sky #1C3274, outline #0A1236, cream #F4EAD5, blue #3E6FD8,
amber #E8A33D, background #0B1230.
